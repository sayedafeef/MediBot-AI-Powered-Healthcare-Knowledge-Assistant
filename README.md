# MediBot - AI Healthcare Knowledge Assistant

A Retrieval-Augmented Generation (RAG) web app that provides accurate, document-backed answers to medical queries using LangChain, Groq, FAISS, and Streamlit.

## Tech Stack
* Python, LangChain, FAISS, Groq API, Streamlit
